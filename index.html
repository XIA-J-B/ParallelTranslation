BEFORE YOU START / 常见问题

再了解一点。

更多使用说明与版本动态，
可在 GitHub 项目主页 ↗ 查看。

需要自己配置 AI 吗？

需要。论文翻译、文章速读和问答使用你配置的模型接口，支持 OpenAI 兼容的 Chat Completions 接口，也可配置自定义 HTTP JSON Agent。模型调用费用由对应服务商计费。离线教学无需配置模型。

论文和笔记保存在哪里？

原 PDF、译文和笔记保存在本机。Windows 桌面版默认使用 %LOCALAPPDATA%\ParallelTranslation。执行翻译或助读时，所需文本、问题与必要的页面图像会发送到你配置的模型服务。

适合哪些 PDF？扫描件可以吗？

主要面向可提取文字的 PDF，单个文件不超过 50 MB、300 页。支持根据单栏、多栏及不同页面特征处理版式；复杂图表、公式或无法可靠排印的区域可能保留原文并给出提示。局部图内英文标签识别不等同于整页扫描件翻译。

支持 macOS、Linux 或 Windows ARM 吗？

目前提供 Windows 10 / 11 x64 安装包，尚未提供 macOS、Linux 和 ARM64 的桌面安装包。后续平台支持请关注 GitHub 发布页。

如何更新？关闭窗口后还会继续翻译吗？

可在软件内检查更新，也可从本页下载新版本覆盖安装，升级默认保留本地数据。关闭窗口默认收起到系统托盘，后台任务继续运行；完全退出请使用托盘菜单。

订阅如何开通？

在软件内「订阅」页面查看基础版 / Pro 权益、商品页与兑换方式。翻译与助读均使用自配模型。
