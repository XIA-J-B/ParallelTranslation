常见问题

更多使用说明与版本动态，
可在 GitHub 项目主页 ↗ 查看。

需要自己配置 AI 吗？

需要。论文翻译、文章速读和问答使用你配置的模型接口，支持 OpenAI 兼容的 Chat Completions 接口，也可配置自定义 HTTP JSON Agent。设置窗口提供接入教程和连接测试。模型调用费用由对应服务商计费。离线教学无需配置模型。

论文和笔记保存在哪里？

导入的 PDF 或 DOCX、译文和笔记保存在本机。Windows 桌面版默认使用 %LOCALAPPDATA%\ParallelTranslation。执行翻译或助读时，所需文本、问题与必要的页面图像会发送到你配置的模型服务。

适合哪些 PDF？扫描件可以吗？

支持文字 PDF，以及扫描版、文字转轮廓版和混合页面，单个文件不超过 50 MB、300 页。扫描页会识别正文，按原栏回排译文。段末可确认的网址保留在原位。图片、表格、公式及上下标周围只排入能可靠识别的正文。识别不清的区域保留原文，OCR 字符仍需核对。

批注怎样使用？可以改署名吗？

选中文字后点「批注」，在页旁直接写下想法，正文保持可见。卡片显示头像、用户名、时间与内容，点击编号回到原文。「个人主页 → 我的账户」可修改用户名与头像；历史批注保留创建时的署名。批注与草稿保存在本机，已保存的批注可以随 Word 或 PDF 文件分享。在线试写一条批注 ↗

怎样和同事交换 Word 或 PDF 批注？

在阅读器右上角点「导出」，选择 Word（.docx）或 PDF。Word 可在「审阅」中查看选区、作者和回复，继续批注或解决讨论。PDF 的高亮、便笺和回复可在支持批注的 PDF 阅读器里查看。将带批注的 DOCX 或 PDF 拖回首页，即可打开为新文档。识别到对应原论文时，也可以只合并批注。首页可直接打开 Word 制作的 DOCX，无须安装 Office。阅读中按 Ctrl+F（⌘F）可全文查找。

支持 macOS、Linux 或 Windows ARM 吗？

目前提供 Windows 10 / 11 x64 安装包，尚未提供 macOS、Linux 和 ARM64 的桌面安装包。后续平台支持请关注 GitHub 发布页。

如何更新？关闭窗口后还会继续翻译吗？

软件进入工作台后自动检查更新，运行中每小时检查一次，收起到托盘时也会检查并自动下载；成功检查后一小时内不重复。下载完成会轻提示，点击「安装并重启」后才保存当前任务并升级。下载可暂停续传，重启软件后可继续；新包下载失败会保留已有安装包。也可随时手动检查，或从本页下载后覆盖安装，升级默认保留本地数据。关闭窗口默认收起到系统托盘，后台任务继续运行；完全退出请使用托盘菜单。

订阅如何开通？

新账号完成邮箱验证后，自动获得 7 天全功能免费试用，全部会员软件功能均可使用。试用与会员一样，需要自配模型接口，模型 API 费用由对应服务商计费。试用结束后，可在软件内「订阅」页面查看基础版、Pro 与 MAX 权益，购买或兑换开通会员。
