# 页间 Parallel

页间是 Windows 10/11 x64 上的论文对照阅读工具。打开论文后，可以并排阅读原文和译文，选中一句话向 AI 提问，或在页旁写下批注，导出给同事回复。

## 最新版本 · [v0.1.30](https://github.com/XIA-J-B/ParallelTranslation/releases/tag/v0.1.30)

启动后，文档库会在后台为已有译文补齐缺失或过期的 PDF 排版，直接复用已保存的译文。文档库会显示正在处理的论文和进度。打开一篇待处理的论文会优先排版，可以先读旧版 PDF 或段落译文。最小化或收起到托盘时继续处理，完全退出后下次启动接着处理。

开启双栏同步后，打开批注、从目录或搜索结果跳转、点击引用时，原文和译文会对准对应位置。调整窗口、缩放或在 PDF 和段落视图间切换，也会保留当前阅读位置。

文章速读能把首轮核对意见中指出的条件错配交给二审，确认后修正正文。二审可以用读到的章节标题、图注或表题核实 PDF 页码；与原文明确冲突的页码会被拦下。速读运行期间可以继续问答，也可以分别查看进度或停止任务。

译文 PDF 能识别更多图内标签和问句，也能在保留公式的同时排入同一文本块里的正文。已有译文会随后台重排复用，新识别的文字可用「继续翻译」补齐。无法确认图形边界的区域会保留原文。

在 Windows 上登录时，应用支持系统信任的代理证书，并会在连接失败时重试一次。连接仍有问题时，会根据情况提示检查证书、代理或网络设置。

## 安装与更新

首次安装时，从官网下载 x64 安装包并运行。已安装的用户可在「版本与更新」中点击「检查更新」。软件运行时也会每小时检查新版并在后台下载，下载完成后点击「安装并重启」即可升级。本机论文、译文、笔记、设置和阅读记录都会保留。

## 和同事交换论文批注

1. 在原文或译文中选中要讨论的句子，点击「批注」写下问题并保存。之后可以点击页边编号回到这条讨论。
2. 在阅读器右上角点击「导出」，选择原文、译文或双语对照。发 Word 文档时，同事可以在 Word 中回复批注。发 PDF 时，同事可以在 WPS 中回复，也可以在 Zotero 中添加便笺后选择「导出 PDF」。
3. 把同事发回的 PDF 或 DOCX 拖入页间首页。识别到原论文后，选择「合并批注到原论文」，便可在原处查看反馈。遇到无法定位的选区，页间会保留意见和引文，并提示你核对位置。
