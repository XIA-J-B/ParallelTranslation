# 页间 Parallel

页间是 Windows 10/11 x64 上的论文对照阅读工具。打开论文后，可以并排阅读原文和译文，选中一句话向 AI 提问，或在页旁写下批注，导出给同事回复。

### 首次使用

- 新手引导先配置翻译模型。选择「DeepSeek 快速接入」会填入官方接口地址和模型名称，并打开 DeepSeek 平台供创建 API Key。也可以手动配置其他服务。连接测试成功并保存后进入下一步。
- 第二步注册或登录页间账号。新用户验证邮箱、设置密码，已有账号可直接登录。两步均须完成，Esc 无法取消。刷新或重新打开后会继续未完成的步骤；已配置模型并已登录的用户可直接阅读。后续六步阅读演示可跳过。
- 未登录时拖入文件翻译，会先保存文件并打开登录界面。登录且具备翻译权限后自动继续；取消登录或选择仅导入原文时可直接阅读原文。

### Windows 桌面稳定性

- 修正 WebView2 跨线程调用，以及等待退出或更新时重复关闭窗口导致的卡死。初始化失败或启动超时会显示错误提示并写入日志。已在本机复现并验证这些故障路径，两位反馈用户的设备仍待复测。

### 论文翻译与排版

- 修复双栏参考文献边界和异常字形导致的正文漏译，改进页码识别和同栏段间距。
- 改进跨块矩阵、积分上下限、分数与行内公式的处理，保留原式字形及编号。改进流程图文字、旋转轴标、表头和文献引文样式。
- 在「修改译文」中可确认原链接对应的中文词组。排版面板分别显示缺译、待核对及保留原图的内容，已核对的照片标签可定位并查看译名。

## 安装与更新

首次安装时，从官网下载 x64 安装包并运行。已安装的用户可在「版本与更新」中点击「检查更新」。软件运行时也会每小时检查新版并在后台下载，下载完成后点击「安装并重启」即可升级。本机论文、译文、笔记、设置和阅读记录都会保留。

## 和同事交换论文批注

1. 在原文或译文中选中要讨论的句子，点击「批注」写下问题并保存。之后可以点击页边编号回到这条讨论。
2. 在阅读器右上角点击「导出」，选择原文、译文或双语对照。发 Word 文档时，同事可以在 Word 中回复批注。发 PDF 时，同事可以在 WPS 中回复，也可以在 Zotero 中添加便笺后选择「导出 PDF」。
3. 把同事发回的 PDF 或 DOCX 拖入页间首页。识别到原论文后，选择「合并批注到原论文」，便可在原处查看反馈。遇到无法定位的选区，页间会保留意见和引文，并提示你核对位置。
