# 页间 Parallel

## 最新版本 · [v0.1.60](https://github.com/XIA-J-B/ParallelTranslation/releases/tag/v0.1.60)

整篇翻译遇到行内公式时，如果模型只是改变了公式标记的括号或大小写，应用现在能识别对应的原式。若模型漏掉公式，应用会指出缺失的位置并重试。批量翻译中，个别段落的公式核对失败时，同批已通过核对的译文可以先保存。

翻译表格时，单元格内的文字意外折行，或模型用不同的负号、科学计数法书写同一个数值，都更容易通过核对。参考文献标题里的晶向编号也能随译名保留，例如材料论文中常见的 [111]。

翻译带编号的小节和算法时，软件名、数据集名称和伪代码可以沿用原文。之前因这些内容中断的论文，更新后点击“继续翻译”，即可接着处理剩余段落。

## 安装与更新

首次安装时，从官网下载 x64 安装包并运行。已安装的用户可在「版本与更新」中点击「检查更新」。软件运行时也会每小时检查新版并在后台下载，下载完成后点击「安装并重启」即可升级。本机论文、译文、笔记、设置和阅读记录都会保留。

## 和同事交换论文批注

1. 在原文或译文中选中要讨论的句子，点击「批注」写下问题并保存。之后可以点击页边编号回到这条讨论。
2. 在阅读器右上角点击「导出」，选择原文、译文或双语对照。发 Word 文档时，同事可以在 Word 中回复批注。发 PDF 时，同事可以在 WPS 中回复，也可以在 Zotero 中添加便笺后选择「导出 PDF」。
3. 把同事发回的 PDF 或 DOCX 拖入页间首页。识别到原论文后，选择「合并批注到原论文」，便可在原处查看反馈。遇到无法定位的选区，页间会保留意见和引文，并提示你核对位置。
