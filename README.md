# 页间 Parallel

页间是 Windows 10/11 x64 上的论文对照阅读工具。打开论文后，可以并排阅读原文和译文，选中一句话向 AI 提问，或在页旁写下批注，导出给同事回复。

## 最新版本 · [v0.1.58](https://github.com/XIA-J-B/ParallelTranslation/releases/tag/v0.1.58)

阅读译文或导出的 PDF 时，可以点击更多子图编号、公式号和文献引用，跳到原稿指定的位置。一处列出多个引用时，只要能与原稿逐项对应，各个编号就能分别点击。

主页论文卡片保留了翻译进度和完成日期，移除了“排版结果”和“翻译总用时”。需要核对某页的排版时，可以打开论文，在阅读器中查看。

参数表里的中文名称能和对应的数值、单位、上下标排在同一行。更多流程图节点和图表纵轴也能在原处显示中文。遇到译文改变公式运算顺序，或图中文字难以与线条分开时，相应位置会保留原文供核对。

参考文献后的附录、只有页眉可选中的扫描正文，现在也能进入翻译。个别段落漏掉公式标记或原样返回时，其他独立段落可以继续翻译。还有正文待识别时，书库会保留待完成状态，已有的导出文件也会保留。

已有论文可以沿用保存的译文。在阅读器右上角点三个圆点，打开“排版与导出”，选择“重新排版”。更换源 PDF 后，重新打开和下载时会核对新稿。新版暂时排不出来时，仍可阅读上一份 PDF。

## 安装与更新

首次安装时，从官网下载 x64 安装包并运行。已安装的用户可在「版本与更新」中点击「检查更新」。软件运行时也会每小时检查新版并在后台下载，下载完成后点击「安装并重启」即可升级。本机论文、译文、笔记、设置和阅读记录都会保留。

## 和同事交换论文批注

1. 在原文或译文中选中要讨论的句子，点击「批注」写下问题并保存。之后可以点击页边编号回到这条讨论。
2. 在阅读器右上角点击「导出」，选择原文、译文或双语对照。发 Word 文档时，同事可以在 Word 中回复批注。发 PDF 时，同事可以在 WPS 中回复，也可以在 Zotero 中添加便笺后选择「导出 PDF」。
3. 把同事发回的 PDF 或 DOCX 拖入页间首页。识别到原论文后，选择「合并批注到原论文」，便可在原处查看反馈。遇到无法定位的选区，页间会保留意见和引文，并提示你核对位置。
